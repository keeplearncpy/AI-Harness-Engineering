# FSD 质量检查清单

> Validator 和 fsd-generator 自检时使用此清单

## 结构完整性
- [ ] 所有必填章节（1-9）均已填写
- [ ] feature_id 符合 kebab-case 命名规范
- [ ] 每个 User Story 包含 role / action / benefit 三要素
- [ ] 验收标准 ≥ 3 条且均可测试

## 需求质量
- [ ] 无二义性描述（不存在"等"、"大概"、"尽量"等模糊词）
- [ ] 异常流程 ≥ 2 种场景
- [ ] 业务规则已显式列出而非隐含在流程中
- [ ] 非功能性需求有具体度量标准

## 数据一致性
- [ ] 核心数据实体已识别且字段类型明确
- [ ] 实体间关系已标注（1:1 / 1:N / M:N）
- [ ] 数据流向描述与 API 端点一致

## 可追溯性
- [ ] 每个功能可追溯到至少一个 User Story
- [ ] 每个验收标准可映射到具体功能点
- [ ] 开放问题已标记 `[待确认]` 并指定负责人/时间

## 下游兼容性
- [ ] 数据实体命名与后续 data-modeler 约定一致
- [ ] API 路径遵循 RESTful 规范
- [ ] 前端页面描述足够支撑 ui_interaction 文档生成
